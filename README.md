# داشبورد خبری بازار — کریپتو، طلا و نقره

داشبورد فارسی RTL با تم تیره که هر **۳۰ دقیقه** به‌صورت خودکار کل زنجیره را اجرا می‌کند:

```
جمع‌آوری ۹۴ منبع رایگان  →  حذف خبر قدیمی‌تر از ۷۲ ساعت  →  اعتبارسنجی محتوایی
   →  ترجمه فارسی تیتر و خلاصه  →  داده بازار + اندیکاتورها
   →  گزارش تحلیلی نهادی (انگلیسی) + ترجمه فارسی + کادر منابع فارسی + نمودار
```

## چه چیزی ساخته شده

| قابلیت | جزئیات |
|---|---|
| **۹۴ منبع** | ۴۳ سایت کریپتو، ۵ منبع فلزات، **۱۴ منبع اقتصاد کلان و وایر (Bloomberg، WSJ، CNBC، ForexLive، MarketWatch Pulse…)**، ۶ منبع پژوهشی، **۱۶ جستجوی زنده Google News** (هر دارایی یکی + ۴ فیلتر وایر Bloomberg/Reuters/WSJ/FT) و **۱۰ فید شبکه اجتماعی (Reddit)** |
| **پنجره خبری ۷۲ ساعت** | خبر قدیمی‌تر اصلاً وارد داشبورد و گزارش نمی‌شود (قابل تغییر: ۲۴/۴۸/۷۲/۱۶۸ ساعت از تنظیمات — روی خود موتور هم اعمال می‌شود) |
| **اعتبارسنجی محتوایی** | امتیاز ۰–۱۰۰٪ از اعتبار منبع + تازگی + جریمه کلیک‌بیت/محتوای کم/ادعای بی‌منبع؛ حذف کامل محتوای اسپانسری و صفحات بی‌ارزش SEO |
| **دروازه ارتباط** | خبرهای بی‌ربط بورسی (سود سهام، ۵۲ هفته، IPO شرکت‌ها) به‌طور خودکار کنار گذاشته می‌شوند |
| **تمام‌فارسی** | تیتر، خلاصه و تاریخ‌ها: تاریخ **شمسی** + ساعت **به وقت تهران** (`۲۴ شهریور ۱۴۰۵، ساعت ۱۷:۱۳`) |
| **گزارش دو‌زبانه** | گزارش English سبک institutional + دکمه «🇮🇷 ترجمه فارسی» درست کنار دکمه Markdown |
| **کادر منابع هر بخش** | زیر هر بخش گزارش (مثلاً «تحلیل تکنیکال») منابع با **نام سایت، تاریخ شمسی، ساعت تهران، امتیاز اعتبار و لینک** — مرتب‌شده بر اساس **بالاترین اعتبار و جدیدترین** |
| **نمودار لایو** | کندل‌استیک واقعی بازار (۵د/۱س/۴س/روزانه) از Yahoo v8 — رایگان و بدون کلید — با بروزرسانی خودکار هر ۶۰ ثانیه و چسباندن قیمت لحظه‌ای به کندل آخر |
| **نمودار تحلیلی** | پنل کنار متن گزارش: قیمت + میانگین‌های ۲۰/۵۰/۲۰۰ + باند بولینگر + حمایت/مقاومت + RSI + MACD + حجم، با توضیح فارسی اینکه هر نمودار به کدام قسمت متن مربوط است |
| **دارایی دلخواه** | از تب «💹 دارایی‌ها» هر دارایی/سهام/فلزی را اضافه کن (نماد Yahoo + شناسه CoinGecko + کلیدواژه خبری) — قیمت، نمودار، خبر و گزارش خودکار برایش ساخته می‌شود |
| **متن کامل خبر** | استخراج کامل متن (JSON-LD → کانتینر مقاله → بزرگ‌ترین بلوک متنی) + دکمه ترجمه فارسی متن کامل |

## اجرا

```
start.bat            ← ویندوز: دابل‌کلیک
```

یا دستی:

```
python -m venv .venv
.venv\Scripts\python -m pip install flask feedparser beautifulsoup4 requests
.venv\Scripts\python app.py --port 5055
```

سپس: **http://localhost:5055**

## بخش‌های داشبورد

| تب | کار |
|---|---|
| 📰 جریان خبر | فیلتر موضوع/دارایی/دسته منبع/منبع + اسلایدر حداقل اعتبار + جستجو؛ تیتر و خلاصه فارسی |
| 📊 تحلیل و گزارش‌ها | گزارش انگلیسی، ترجمه فارسی، دانلود Markdown، کادر منابع فارسی هر بخش، نمودار کنار متن |
| 💹 دارایی‌ها | افزودن/حذف دارایی دلخواه + جدول وضعیت (نماد Yahoo، CoinGecko، قیمت، تعداد خبر) |
| 📡 منابع خبری | ۹۴ منبع گروه‌بندی‌شده، روشن/خاموش، تعداد خبر هر منبع، افزودن فید RSS دلخواه |
| ⚙️ تنظیمات | تناوب (۵/۱۵/۳۰/۶۰/۱۲۰ دقیقه)، پنجره خبری، دارایی‌های فعال، گزارش خودکار |

## فایل‌ها

| فایل | نقش |
|---|---|
| `app.py` | سرور Flask، زمان‌بند، API‌ها، استخراج متن کامل، رزولوشن لینک گوگل‌نیوز |
| `dashboard_html.py` | کل رابط کاربری فارسی (HTML/CSS/JS) |
| `sources.py` | ۹۴ منبع، تاکسونومی، دروازه ارتباط، مدل اعتبارسنجی |
| `scraper.py` | جمع‌آوری موازی (شبکه‌های اجتماعی سریالی)، قواعد تازگی، dedupe |
| `translate.py` | مترجم فارسی (بدون کلید API) با کش دیسکی |
| `fa_format.py` | اعداد فارسی، تبدیل تاریخ شمسی، ساعت تهران |
| `market_data.py` | قیمت/تاریخچه OHLC از Yahoo Finance + بازار CoinGecko + کش |
| `indicators.py` | EMA، RSI، MACD، ATR، بولینگر + سری‌های نمودار |
| `report_generator.py` | گزارش انگلیسی، انتخاب اخبار بر اساس اعتبار/تازگی، کادر منابع فارسی |
| `smoke_test.py` | تست کامل زنجیره بدون سرور (تازگی، ترجمه، نمودار، گزارش) |

## نکته‌های مهم

- **گزارش تکنیکال** همیشه ≥۴ پاراگراف دارد؛ بخش‌های بدون داده (مثل مشتقات) حذف یا صریحاً «data gap» علامت‌گذاری می‌شوند — هیچ داده‌ای ساخته نمی‌شود.
- **X (توییتر)** API رایگان RSS ندارد؛ پوشش شبکه‌های اجتماعی از **Reddit** و **جستجوی Google News** (که پست‌های شبکه‌های اجتماعی را هم ایندکس می‌کند) می‌آید. اگر پل RSS دیگری داری، از تب «منابع خبری» اضافه‌اش کن.
- خبرهایی که از Google News می‌آیند لینک **رمزنگاری‌شده** دارند؛ ربات تلاش می‌کند آدرس اصلی را از موتور جستجو پیدا کند و اگر مطمئن نباشد، به‌جای لینک اشتباه، دکمه «جستجوی متن کامل» نشان می‌دهد.
- تست سریع بدون سرور: `.venv\Scripts\python smoke_test.py`
